# Support / 支持

- Questions & ideas: open a GitHub Discussion or an issue in the relevant repository.
- Protocol changes: propose a WIP in [`wutong-protocol`](https://github.com/project-wutong/wutong-protocol/tree/main/wip).
- Security: **never** use public issues — see SECURITY.md.

使用问题请在对应仓库提交 Issue；协议变更请提交 WIP；安全问题请私下报告。
